## عامل اجرایی هوشمند — `AI_Agent_OLLAMA`

- **ماهیت:** ai
- **دسته:** `ai-assistants`
- **مسئله:** اجرای کارهای تکراری توسعه و مدیریت فایل معمولاً نیازمند جابه‌جایی میان ترمینال، پیام‌رسان و رابط‌های مختلف است. این عامل یک مسیر گفتگویی با تأیید و ثبت عملیات برای آن‌ها ایجاد می‌کند.
- **مشتری هدف:** تیم‌های فنی و توسعه‌دهندگان؛ مدیران سیستم علاقه‌مند به اتوماسیون کنترل‌شده
- **Commit کامل:** `df8243f082f0198af814566f18bfcd682b6cf1d8`

### قابلیت‌های تأییدشده
- **اجرای برنامه‌محور با ابزارهای واقعی:** برنامه‌ریزی و فراخوانی ابزارهای فایل، شل، وب و سیستم در چرخه محدودشده.
- **تأیید عملیات حساس:** درگاه تأیید برای تغییرات و اقدامات پرریسک با سقف چرخه اجرا.
- **رابط‌های وب، دسکتاپ و پیام‌رسان:** اشتراک موتور عامل میان تجربه محلی و ربات‌های تلگرام و بله.
- **انتخاب ارائه‌دهنده مدل:** پشتیبانی کد از Ollama و سرویس‌های OpenAI-compatible از جمله GapGPT و AvalAI.
- **ثبت گفتگو و رویداد:** ذخیره SQLite گفتگوها و جزئیات امن رویدادها برای پیگیری.

### پیش‌نیازها
- Python و وابستگی‌های نسخه انتخابی
- Ollama یا کلید سرویس مدل سازگار
- تعیین WORKSPACE_ROOT و فهرست کاربران مجاز

### محدودیت‌ها
- اجرای ابزارهای دسکتاپ به سیستم‌عامل و وابستگی‌های گرافیکی وابسته است.
- عملیات تغییردهنده باید با سیاست تأیید و در محیط ایزوله پیکربندی شوند.
- دسترسی Gmail یا تلگرام نیازمند اعتبارنامه و راه‌اندازی جداگانه است.

### موارد ناقص یا نیازمند بررسی
- برخی قابلیت‌ها وابستگی اختیاری و محدودیت سیستم‌عامل دارند؛ تست زنده تمام سرویس‌های خارجی بخشی از این بررسی نبوده است.

### فناوری‌های مشاهده‌شده

Python, Ollama, OpenAI-compatible API, SQLite, FastAPI, PySide6

## SoroPy — `soropy`

- **ماهیت:** library
- **دسته:** `social-automation`
- **مسئله:** ساخت اتوماسیون پایدار پیام‌رسان بدون لایه انتزاع نیازمند مدیریت مرورگر، نشست، رویداد و جزئیات پروتکل است.
- **مشتری هدف:** توسعه‌دهندگان Python؛ تیم‌های فنی سازنده اتوماسیون اختصاصی
- **Commit کامل:** `7711aeb3e0022a152355caaee6c0f16ec9f50df9`

### قابلیت‌های تأییدشده
- **دو backend مستقل:** Selenium برای وب‌کلاینت و WebSocket/MTProto برای اجرای realtime بدون Chrome.
- **پیام و رویداد:** ارسال، پاسخ، دریافت رویداد و auto-reply با پیش‌فرض فقط PV.
- **فایل و مدیریت گفتگو:** ارسال و دانلود فایل، ویرایش، حذف و pin در backend پشتیبانی‌شده.
- **مخاطبین و moderation:** مدیریت مخاطب، مسدودسازی و عملیات گروهی متناسب با دسترسی.
- **چند حساب و نشست پایدار:** مدیر چندحسابی و ذخیره نشست جداگانه برای هر backend.

### پیش‌نیازها
- Python و وابسته‌های backend انتخابی
- حساب آزمایشی و کد ورود
- SPlusthon و extras برای WebSocket

### محدودیت‌ها
- backend WebSocket از کلاینت شخص ثالث MTProto استفاده می‌کند نه API رسمی عمومی.
- بعضی قابلیت‌ها فقط در WebSocket و با دسترسی مدیر گروه در دسترس‌اند.
- استفاده باید مطابق قوانین سروش‌پلاس و بدون ارسال ناخواسته باشد.

### موارد ناقص یا نیازمند بررسی
- قابلیت‌ها به تغییرات سروش‌پلاس و SPlusthon وابسته‌اند و نیازمند تست دوره‌ای با حساب آزمایشی‌اند.

### فناوری‌های مشاهده‌شده

Python, Selenium, WebSocket, MTProto, SQLite, aiohttp
